# Arsitektur & API
- Frontend app.medisin.id: Vue 2 + Quasar v1 (QSelect/QInput/QTabs/QTable), Vuex. Akses VM: `el.__vue__`. Root: `$router`, `$store`, `$axios` (base https://old-ci.medisin.id/, header X-API-KEY, X-TOKEN, X-APP-DEV), komponen punya `$klinik` (axios base https://backends.medisin.id/api/klinik/, header Authorization Bearer + X-API-KEY), `$rest2` (dipakai bpjs/pcare), `$socket` (socket.io trigger).
- Respons cepat: kebanyakan 80–370 ms. GET master/kunjungan ~576 ms.
- Antrean POLI: GET klinik/master/antrian?status_antrian[]=201,202,203&tgl_awal&tgl_akhir&page&rowsPerPage&descending&search → {data:[antrian+kunjungan nested], pagination:{total,current_page,per_page,last_page}}.
- Tombol "Pelayanan" di antrean (doPelayanan): PUT klinik/master/antrian/{antrian_id} {first_open:true,status_antrian:203,kunjungan,trs_id} lalu router ke `pelayanan-proses` {tab:'Diagnosa', id_kunjungan: btoa(id_kunjungan)} → URL /admin/pelayanan/proses/Diagnosa/<base64 id>.  (MENGUBAH status antrean.)
- Membuka URL proses langsung (tanpa doPelayanan) hanya GET (tidak mengubah status) — aman untuk membaca.
- Kode status antrian: 201/202 menunggu, 203 Sedang Dilayani (poli), 204 Selesai, 302 perawat, 401 farmasi, 502 kasir, 601 lab, 701 odontogram. Tombol PROSES PERAWAT/POLI/FARMASI/LABORATORIUM/ODONTOGRAM/KASIR = prosesPelayanan(kode): PUT master/antrian/{antrian_id} {kunjungan, status_antrian, trs_id} + socket emit. Untuk 502 (kasir) ada dialog validasi (anamnesa/CPPT lengkap).
- Saat halaman proses dibuka: GET lib/load/penjamin, GET master/kunjungan?id_kunjungan, old-ci lib/load/statuspulang & kesadaran, POST master/dokter/load-dokter {poli_id}, POST tab/get-data-tab {poli_id} (konfigurasi tab per poli), kunjungan-icd-o, kunjungan-ptm, satusehat position lab, poli-kluster, icare (500 di trial).
- Objek kunjungan (pasien) datar, ~786 field: keluhan, keluhan_lainya, berat_badan, tinggi_badan, imt, suhu, sistole, diastole, saturasi, resp_rate, heart_rate, nadi, terapi, kesadaran_id, status_pulang, pemeriksaan fisik (paru/jantung/tht/mata...), satusehat_* id, pcare_integrasi, noKunjungan_pcare, dll.
- SUBMIT (saveData): PUT klinik/master/kunjungan/{id_kunjungan} {pasien:<objek kunjungan penuh>}; lalu bila pcare_integrasi & klinik online: POST (rest2) bpjs/pcare/kunjungan {pasien_id, antrian_id, kunjungan_id} → KIRIM KE BPJS. Jadi SUBMIT pada pasien BPJS = kirim PCare.
- SUBMIT SATUSEHAT = kirim ke SatuSehat (pihak luar).
